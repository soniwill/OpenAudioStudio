Como usar este manual

Se você nunca usou um programa de áudio interativo antes, comece pelo Capítulo 0 — Conceitos Básicos. Se você já conhece o básico e quer entender um painel específico do OpenAudio Studio.exe ou um componente da Unity, use o menu lateral ou a busca instantânea acima.
