# Blueprints legados

O [blueprint consolidado](blueprint.md) preserva o arquivo anteriormente identificado pelo sufixo `_fix.md`. A [versão original](blueprint-original.md) registra o histórico anterior à consolidação. Ambos ficam congelados para consulta.

O [índice de capacidades](../specs/README.md) associa as seções numeradas do blueprint e os documentos de `docs/specs/` a cada capacidade OpenSpec. Consulte essas referências para capacidades que aguardam migração. Os contratos migrados passam a residir em `openspec/specs/`. Proponha requisitos novos e refinamentos em [openspec/changes](../../openspec/changes/).
